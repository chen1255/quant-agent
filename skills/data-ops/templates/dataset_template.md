# 数据入库单（模板）

> 复用本结构生成取数记录。带 `{}` 的为占位说明，正式输出时替换；不适用的小节保留标题并注明"无"。

## 一、数据需求

| 项 | 内容 |
|---|---|
| 目标 | {更新行情 / 补齐区间 / 刷新台账 / 交易日历入库} |
| 标的 | {如 600519.SH、510300.SH、159915.SZ} |
| asset_type | {stock / etf / index} |
| 请求区间 | {yyyy-MM-dd ~ yyyy-MM-dd} |
| 复权口径 | {none / qfq / hfq} |
| 观察日 as_of | {基本面的 as_of_date，无则写"不涉及"} |

## 二、标的归一化

| 输入 | 归一化代码 | 名称 | asset_type | lot_size | 状态 |
|---|---|---|---|---|---|
| {510300} | {510300.SH} | {沪深300ETF} | {etf} | {100} | {active/delisted} |

> 退市标的（`delist_date` 非空）必须保留，不得剔除。

|---|---|---|---|---|
| {600519.SH} | {yyyy-MM-dd} | {N} | {…} | {…} |

## 五、口径与局限声明

- 复权口径：{none/qfq/hfq}；量（volume/amount）恒为未复权原始口径。
- 基本面：仅 `pub_date <= as_of_date` 的记录入库；无公告日记录已丢弃 {N} 条。
- 指数成分：`point_in_time = {false}`（免费源只提供当前成分，历史成分无法保证）。
- 上游 warnings：{逐条列出；无则写"无"}。

## 六、未完成事项

- 失败标的与原因：{标的 + error.code + message；无则写"无"}
- 下一步建议：{如"稍后重试 / 换用本地缓存 / 补充付费源"}。
- 声明：本单只完成取数与入库，未做任何分析判断。
